1. Product status

GuideCursor is currently in pre-release development. The website includes an interactive browser preview and information about the native macOS application. The site does not currently process purchases or distribute a general public production installer.

This privacy notice describes the behaviour of the website as built. The native macOS application has separate permission and data-handling requirements and remains subject to release-readiness review before broader workplace deployment.

2. What information we handle

Website interaction

The current website does not ask for operating-system screen recording or macOS Accessibility permission and does not capture your desktop. The interactive Mail journey is a browser preview and does not inspect your desktop.

Local site state

The browser stores limited state locally so the site can remember update acknowledgements and your cookie choice.

Technical request data

Like most websites, the hosting and delivery infrastructure necessarily receives technical request data when it serves a page, such as the requested URL and connection metadata. GuideCursor does not use this website to build advertising profiles from that data.

Native macOS application

The macOS app requires Accessibility permission to read control metadata in supported applications. The product architecture is local by default; screenshot-based fallback is intended to stay on device, and opt-in cloud inference would receive only a text candidate list rather than screenshots.

3. Why the site uses data

We use browser-side state only to provide site features you explicitly request, including remembering that a deployment update was acknowledged and remembering privacy preferences.

Optional consent categories are separate from essential site functionality. The current website does not load a third-party analytics or advertising SDK, even if you enable an optional category in the preference centre.

5. External services

The site is deployed through Vercel infrastructure and loads font resources from Google Fonts. Following research-paper links or other external links will take you to third-party websites with their own privacy practices.

GuideCursor does not currently embed advertising pixels, behavioural advertising tools or a third-party analytics SDK on this website.

6. Your data-protection rights

Where the GDPR applies, individuals can have rights such as being informed, accessing personal data, correcting inaccurate data, requesting erasure or restriction, receiving portable data and objecting to certain processing. Consent can also be withdrawn where processing relies on consent.

Because most website state is stored only in your own browser, the quickest way to remove it is to clear it locally using the control below.

Project contact. GuideCursor does not yet publish a dedicated privacy contact address. Questions can be raised through the same channel used to provide preview access.

7. Retention

Local site state remains in your browser until you clear it, clear site storage or the implementation changes. The consent cookie is configured for up to 180 days. Additional retention periods would be defined before broader commercial data processing is introduced.

8. Your privacy controls

You can reopen the cookie preference centre at any time or clear the GuideCursor local site state from this browser.

Clearing local site data removes GuideCursor deployment/update state saved in this browser. Your current cookie preference is preserved unless you clear it separately in Cookie settings.
