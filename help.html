18 ARTICLES

GuideCursor is a student concept for an assistive cursor layer that helps a person locate and reach controls inside mainstream software. The website demonstrates the idea, while the separate desktop application is still to be built.

The core principle is guidance rather than invisible autopilot: the user keeps control of the final action.

Choose Try GuideCursor from the site. You will first select a visual, hearing-focused or reduced-motor profile, and you can switch profiles during the demo.

The Use Cases page explores workplace software, education portals, public-service forms, banking interfaces, creative tools and everyday system settings. Those are concept scenarios, not claims that a desktop product currently supports each application.

It uses browser speech synthesis for spoken task and directional guidance, high-contrast target highlighting and an assisted target zone. Voice can be toggled or repeated from the demo panel.

The hearing profile switches the main on-site demo to a simulated meeting with live captions, visual labels for non-speech sounds, caption controls and a persistent transcript. It is meant to show how assistance can be visual-first rather than simply turning audio off.

The demo increases the effective click zone around the intended target and strengthens snap-style assistance as the pointer approaches. Clicking inside the enlarged assisted area can activate the intended demo control even when the pointer is not pixel-perfect.
