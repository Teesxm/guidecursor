# GuideCursor Landing Page MVP

GuideCursor is an assistive cursor concept for the VU Digital Business & Information Systems assignment.

This branch replaces the previous RoleQuest demo with a high-fidelity GuideCursor landing page. The site is intentionally designed as a premium product concept rather than a generic card-based SaaS template.

## What the landing page demonstrates

- Animated cursor guidance through a familiar email interface
- Task switching for attach-file, folder and downloads examples
- Parallax scrolling and scroll-linked transitions
- The core system flow: perceive, understand, guide, assist
- The difference between assistive guidance and autonomous agents
- Separate interaction modes for blind / severe vision loss, low vision and reduced motor control
- A macOS-first desktop product preview
- The four research foundations used in the GuideCursor concept brief
- Responsive layouts and reduced-motion support

## Stack

- Vite
- Static HTML/CSS/JavaScript for a deterministic presentation demo
- Existing React/Motion dependencies remain available for the later app prototype
