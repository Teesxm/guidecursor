01 · WHAT EXISTS NOW

Prototype pieces are real.
The product promise is not finished.

The development branch is much closer to the October paper than the old website demo, but it should be described as a prototype under test rather than a finished download.

IMPLEMENTED FOUNDATION

Native Swift macOS app

A separate macOS application now exists alongside the website rather than only a browser simulation.

IMPLEMENTED FOUNDATION

Accessibility control discovery

The prototype scans labelled controls across macOS apps and has added work for nested accessibility labels and cross-app diagnostics.

IMPLEMENTED FOUNDATION

Guidance + speech

The prototype can follow the real cursor with a click-through visual overlay and spoken directional guidance while preserving user clicks.

IMPLEMENTED FOUNDATION

Local-model option

Optional Ollama target suggestions are part of the prototype direction so local inference can be compared against cloud capability.

IMPLEMENTED FOUNDATION

Visual fallback groundwork

Permissioned screenshot/OCR work has been added, including offline evaluation and native Vision OCR checks.

THE REAL GATE

Live end-to-end reliability

The next meaningful milestone is not more marketing surface. It is proving one real Mail/file-picker journey on an installed Mac and recording the failures.

02 · NOT READY TO CLAIM

No simulated installers.
No Windows download.

The current site now separates prototype status from product scope instead of pretending downloadable binaries already exist for multiple platforms.

STILL TO VERIFY

Live target matching and full journey

The team still needs to prove the core Mail → file picker → Open flow works reliably with the installed app, including the overlay, speech, Zoom behaviour and model quality.

OUTSIDE FIRST VERSION

Windows and other impairments

Windows, hearing support, motor support, broad application support and autonomous task completion are no longer presented as current downloadable capabilities.

03 · NEXT VERIFICATION

What should happen before “Download”.

The native prototype becomes meaningful when the team can demonstrate the paper’s core journey with evidence, not just compile the app.

Core installed-Mac test

Open a draft email in Mail, state “attach my CV”, verify the Attach target, guide to it, transition into the file picker, clarify ambiguous CV files if needed, then verify and guide to Open without the software performing any click.

1. Accessibility permission stable across the installed build
2. Attach found and verified in live Mail
3. File picker re-scanned after the user click
4. Ambiguous files trigger clarification
5. Open verified and guided without auto-click
6. Failures recorded in development log
