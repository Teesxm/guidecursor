02 · CURRENT BOUNDARIES

macOS first.
Focused by design.

GuideCursor is currently focused on macOS visual access. Wider platform and impairment support will follow only when the core interaction model is dependable.

UNDER VALIDATION

Live target matching and full journey

The Mail → file picker → Open flow is still being validated across target identification, overlay behaviour, spoken guidance, Zoom integration and model quality.

NOT YET SUPPORTED

Windows and broader impairment support

Windows, hearing-focused assistance, motor-focused assistance, broad application coverage and autonomous task completion are not part of the current macOS preview.

03 · RELEASE READINESS

What must be solid before wider access.

Wider access depends on the complete workflow being reliable on installed Macs, not simply on the application compiling successfully.

Core release-readiness workflow

Open a draft email in Mail, request “attach my CV”, verify Attach, transition into the file picker, clarify ambiguous files if needed, then verify and guide to Open without GuideCursor performing the click.

1. Accessibility permission stable across the installed build
2. Attach found and verified in live Mail
3. File picker re-scanned after the user click
4. Ambiguous files trigger clarification
5. Open verified and guided without auto-click
6. Failures captured and used to improve guidance

Private preview, public principles.

GuideCursor is not yet distributed as a general public download. The product site documents the interaction model, privacy boundary and supported workflow while native release-readiness work continues.
