1. Scope

These terms apply to the GuideCursor website and its interactive previews. GuideCursor is currently in pre-release development and is provided for evaluation and product testing.

2. Product status

GuideCursor is not yet a general public production release. Current support is focused on visual access on macOS, with a limited set of supported workflows. Hearing-focused assistance, motor-focused assistance and Windows are not currently supported.

The browser site demonstrates the interaction model. A native Swift application is under active development and testing and is currently distributed only as a limited preview.

3. Commercial status

The website does not currently process purchases. GuideCursor is designed for annual workplace licensing, with commercial terms defined per deployment. Nothing on this site creates a subscription, purchase or software licence.

4. macOS preview

A native macOS application is in pre-release development. Preview builds and test artefacts are development material and are not a general public production release. Windows is not currently supported.

5. Acceptable use

You may explore the website, interact with the preview and use it for ordinary evaluation and product-research purposes. You should not attempt to disrupt the site, bypass technical controls, impersonate another person, submit unlawful content or use the preview to collect other people's sensitive information.
