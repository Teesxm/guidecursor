ACCESSIBILITY

Accessibility is nota side setting.

GuideCursor is built around the idea that people should be able to use mainstream software with assistance that adapts to them while preserving control.

1. Our accessibility commitment

The GuideCursor concept is designed around human agency and accessible interaction. The website aims to support keyboard use, reduced-motion preferences, readable contrast, clear focus states and alternatives to audio-only interaction.

2. Website accessibility features

  • Keyboard-accessible navigation and interactive controls across the core site.
  • Reduced-motion styles for users who prefer less animation.
  • Text labels for key controls rather than relying only on icons.
  • High-contrast visual states for the GuideCursor demos.
  • Caption/transcript simulation in the hearing-assistance showcase.
  • Spoken guidance controls in the visual-impairment demo.

3. Accessibility demo modes

The interactive concept offers visual impairment, hearing impairment and reduced motor-function profiles. These are product demonstrations, not medical assessments or production assistive technology.

Human control stays central. The concept guides, enlarges effective targets and communicates state, but the user remains responsible for the final interaction.

4. Known limitations

This is a rapidly changing student MVP and has not been independently certified against a specific accessibility standard. Some simulated interfaces, animated demonstrations and browser-generated speech may behave differently across browsers, assistive technologies and operating systems.

Before commercial launch, GuideCursor would need formal testing with disabled users, assistive-technology compatibility testing and a documented accessibility-conformance process.

5. Accessibility feedback

If you encounter a barrier in this concept build, share it with the project team through the same channel through which you received access to the MVP. Include the page, browser, device and assistive technology used if relevant.
